# Security Policy

## Supported versions
Only the latest release of Holm gets security fixes.
Please update to the latest version before you report a problem.

## Report a vulnerability
Do not open a public issue for a security problem.
Use one of these ways (currently only one option):

Send an email to djordje.mojsilovic@avtoris.studio.

Please include:
- the Holm version and the Windows version
- the steps to repeat the problem
- the impact you see
- a proof of concept, if you have one

## What to expect
- We confirm that we got your report within 14 days.
- We tell you our plan within 25 days.
- We fix confirmed problems as fast as we can.
- We credit you in the release notes, if you want.

## Scope
In scope:
- friend codes and friend requests
- Beam file transfer (direct, code based, and QR code)
- the encryption of transfers and notes
- the handling of data from third party services

Out of scope:
- problems inside third party services themselves
- attacks that need full control of the user's PC

## Safe harbor
We will not act against you if you test in good faith,
test only your own installation, do not access data of other
people, and report the problem to us privately.
