UP AND RUNNING

Three small steps.

The installation guide →
  1. 01

    Download.

    Choose the self-contained Holm.exe or extract the Windows ZIP. On Linux, unpack the tar.gz archive. No separate .NET runtime needed.

  2. 02

    Make a home for it.

    Keep Holm.exe in a folder your account can write to. That lets the portable updater do its job.

  3. 03

    Look up.

    Run Holm.exe on Windows or ./Holm on Linux. Open the notch to explore. Right-click for Settings and make it yours.

A note on first launch.

The current GitHub build is unsigned. Windows SmartScreen may warn, and Smart App Control may block an unsigned app. Review the official release before running it. Read the installation notes →
