Holm 1.12.1 opens with Ctrl+H.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.12.1-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Holm is not code-signed. Windows SmartScreen may warn on first launch; Smart App Control may block an unsigned app.

### Added
- **Ctrl+H opens the notch.** Press Ctrl+H anywhere to open the notch, and again to close it; a click elsewhere closes it too. While it's on, other apps don't get Ctrl+H (browser history, Replace in editors): *Settings › General › Ctrl+H opens and closes the notch* turns it off.
