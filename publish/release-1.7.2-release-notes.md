Holm 1.7.2 lets you close the screenshot pop-out with a click.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.7.2-win-x64.zip** | Everyone. Unzip and run `Holm.exe`, nothing to install. |
| Holm-1.7.2-win-x64-dotnet10.exe | Smaller single exe if you already have the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0). |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

> **“Windows protected your PC”?** The app is not code-signed, so SmartScreen warns on first launch. Click **More info → Run anyway**. Windows Firewall may also ask once – allow it if friends on your network should find you for Beam.

### Changed
- **Screenshot pop-out.** A click on its empty space (not on *Send*, *Shelf*, *Copy text* or the picture) closes it. Other pop-outs are unchanged.
