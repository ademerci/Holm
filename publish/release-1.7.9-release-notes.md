Holm 1.7.9 lets you open a beamed file straight from the notch.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.7.9-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's automatic updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Holm is not code-signed, so Windows SmartScreen may warn on first launch. Click **More info → Run anyway** to launch it.

### Added
- **Open a beamed file from the notch.** After you accept a Beam transfer, the saved pop-out offers *Open* as well as *Show*, like a finished browser download – so you can open the file without going through Downloads in Explorer.
