## What’s new

- **Send files from chat.** Choose one or more files with the new plus button to send them to your friend using Beam. The GIF button is now next to Send.
- **Updates in Settings.** Check for updates, install a new version, and choose whether Holm checks automatically. Update notifications still appear in the notch.

Holm for Windows x64 is self-contained: download `Holm.exe` or the ZIP and run it; no .NET installation is needed.
