Holm 1.9.5 lets you send files from a chat and brings update controls into Settings.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.9.5-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Holm is not code-signed. Windows SmartScreen may warn on first launch; Smart App Control may block an unsigned app.

### Added
- **Files in chat.** Click *+* at the left of the message box and choose one or more files to send to that friend. Beam asks them to accept and shows progress in the notch. If *Send later* is on, files for an offline friend wait until their Holm is back. Beam must be on.

### Changed
- **Updates in Settings.** *Settings › Updates* shows your version and lets you check for a release, update and restart, or turn automatic checks on or off. Checks are on by default; the existing update notifications stay in the notch. The old right-click submenu is gone.
- **The message box.** The GIF picker is beside the send arrow, and the file button has a round hover highlight.

### Fixed
- **GIF search.** The 1.9.5 downloads now include the GIPHY key. If you downloaded 1.9.5 before this fix, download it again to get the corrected app.
