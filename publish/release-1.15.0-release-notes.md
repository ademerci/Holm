Holm 1.15.0, Skokholm, brings blue skies and green hills to Frutiger Aero, gives the Jelly Easter egg a little more wobble, and fixes long messages getting cut off in chat.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.15.0-win-x64.zip** | Unzip and run `Holm.exe`. Holm's updater uses this file too. |
| **Holm.exe** | Run the self-contained app directly. No .NET installation needed. |
| **Holm-1.15.0-linux-x64.tar.gz** | Unpack and run `./Holm`. No .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64, or Linux x64 with X11 (Wayland through XWayland).

Holm is unsigned. Windows SmartScreen may warn on first launch, and Smart App Control may block an unsigned app.

### Added
- **Island names.** This series is called Skokholm. The Holm window shows the name beside the version number.

### Changed
- **Frutiger Aero.** Blue skies, green hills and glossy water bubbles come to the open notch and the Holm window. The notch's buttons and cards have a glass finish. Pick it under *Settings › Design*. Classic is still the default.
- **A little more Jelly.** The Easter egg now makes the notch lean when you drag it and the Holm window wobble when you click or move it.

### Fixed
- **Long chat messages wrap.** Sent and received messages stay inside the conversation, even when a long word has no spaces.
