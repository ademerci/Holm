Holm 1.12.6 shows how much of your AI coding agents' limits you've used, right beside the notch.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.12.6-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Holm is not code-signed. Windows SmartScreen may warn on first launch; Smart App Control may block an unsigned app.

### Added
- **AI usage beside the notch.** A small black circle at the notch's right shoulder shows the coding agent that matters most right now (Claude Code or Codex) with its mark inside a thin ring that fills with its usage. It's there in every closed state, also while music plays, and flattens into a capsule beside the minimized notch. Hover it for a calm card: the percentage, when it resets, and which sessions are working on which project and step. Codex logs its real 5-hour and weekly limits; Claude Code logs only tokens, so its ring compares the current 5 hours with your busiest 5 hours this week. Read only from the tools' own logs on your PC, never sent or shared. *Settings › General › AI usage ring* turns it off.

### Fixed
- **Snapshots stay private.** Holm's picture mode no longer lets a friend's real chat message pop out over a pose.
