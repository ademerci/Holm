Holm 1.9.2 brings Instagram-style reactions and GIFs to the chat and an equalizer that dances to your music.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.9.2-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's automatic updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Reactions and GIFs need your friends on Holm 1.9.2 too; on older versions a GIF shows as its link and reactions don't show.

Holm is not code-signed, so Windows SmartScreen may warn on first launch. Click **More info → Run anyway** to launch it.

### Added
- **Reactions.** Hover a message and click the smiley for ❤️ 😂 😮 😢 😡 👍, or *+* for every emoji; double-click a message for a heart. You and your friend both see the reactions. React right from the notch when a message pops out, and change your quick reactions with *Customize reactions*.
- **GIFs.** *GIF* next to *Send*: search GIPHY or pick a recent GIF, or paste any GIF link. GIFs play in the chat, in the conversation list and in the notch. (Search needs a free GIPHY API key, pasted into the picker once.)
- **Equalizer that follows the music.** The bars in the closed notch now move with the beat of what plays. Only the loudness is read, nothing is recorded. *Settings › General* switches back to the classic bounce.
