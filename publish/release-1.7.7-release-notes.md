Holm 1.7.7 shows your Focumon in the closed notch and picks the right monster.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.7.7-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's automatic updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Holm is not code-signed, so Windows SmartScreen may warn on first launch. Click **More info → Run anyway** to launch it.

### Added
- **Focumon in the closed notch.** While you focus or take a break, the closed bar shows your monster and timer instead of the weather. Needs the companion extension in `extension/focumon` (load unpacked in Chrome/Edge).
- **Focumon for Holm browser extension.** Reads your blue *Productive Me!* floor bubble and tells Holm on this PC only (`127.0.0.1`).

### Fixed
- **Wrong Focumon sprite.** The extension now selects your monster, not another trainer's from the party row or floor.
