Holm 2.0.1 — Herm brings the remaining toolbox controls into Start page and improves alignment in Chat.

## Download

| File | For whom |
| --- | --- |
| **Holm-2.0.1-win-x64.zip** | Unzip and run `Holm.exe`. Holm's updater uses this file too. |
| **Holm.exe** | Run the self-contained app directly. No .NET installation needed. |
| **Holm-2.0.1-linux-x64.tar.gz** | Unpack and run `./Holm`. No .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64, or Linux x64 with X11 (Wayland through XWayland).

Holm is unsigned. Windows SmartScreen may warn on first launch, and Smart App Control may block an unsigned app.

### Changed
- **Start page settings.** Toolbox visibility, Media controls and Focumon are in Settings › Start page. Clipboard recording is under Calls and privacy.
- **AI usage icons.** The toolbox, Start page preview and AI usage settings use a speedometer icon.

### Fixed
- **Chat alignment.** The Add a friend button is centered beside Search, and the message placeholder and text are centered in the composer.
