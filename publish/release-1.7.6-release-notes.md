Holm 1.7.6 shows your Focumon monster and timer in the open notch.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.7.6-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's automatic updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Holm is not code-signed, so Windows SmartScreen may warn on first launch. Click **More info → Run anyway** to launch it.

### Added
- **Focumon in the open notch.** With the Focumon browser extension installed and talking to Holm on this PC, your monster and focus/break timer appear in the open notch's top bar (next to the sleep timer). A click opens Focumon. Toggle it under *Settings › Open notch*; on by default. Without the extension, nothing is shown.
