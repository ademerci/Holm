Holm 1.10.0 makes adding friends as easy as sharing a short code, and stops friends from disappearing.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.10.0-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Holm is not code-signed. Windows SmartScreen may warn on first launch; Smart App Control may block an unsigned app.

### Added
- **Invite codes.** Open *Add a friend* (in the Holm window, the *+* beside the chat search, or Friends › *Add a friend…* in the right-click menu) and you get a short code like `HOLM-7KQ2X-9XF4M`. Send it, paste it into a chat or read it out. A friend who types it into their *Add a friend* page is your friend right away: nobody has to accept anything. A code works for everyone you give it to for 12 hours; *New code* makes another.
- **Copied codes pop out.** Copy someone's invite code from a chat and the notch offers to add them.
- **Requests in one place.** *Add a friend* lists the requests you can accept or decline, and the ones you sent (*Withdraw*).

### Fixed
- **Friends no longer disappear.** A friend request that wasn't answered within 2 minutes used to be withdrawn, and could take a friend who had already said yes off their list again. Requests now stay open until they're answered, and a late yes still makes you friends.

Invite codes need your friend on Holm 1.10 too. A friend on an older Holm can still use your long friend code: *Add a friend* › *Copy my long friend code*, and their long code works in the same box.
