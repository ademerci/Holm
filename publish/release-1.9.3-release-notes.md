Holm 1.9.3 makes GIF search work right away: no GIPHY key to set up any more.

## Download

| File | For whom |
| --- | --- |
| **Holm-1.9.3-win-x64.zip** | Unzip and run `Holm.exe`; also used by Holm's automatic updater. |
| **Holm.exe** | Run the self-contained app directly; no .NET installation needed. |

Requires Windows 10 (2004 or newer) or Windows 11, x64.

Holm is not code-signed, so Windows SmartScreen may warn on first launch. Click **More info → Run anyway** to launch it.

### Changed
- **GIF search out of the box.** *GIF* next to *Send* searches GIPHY straight away; you no longer need to paste an API key first. A key you added yourself keeps working.
