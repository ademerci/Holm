# Store screenshots

These PNGs were rendered with Holm's built-in demo snapshot mode from version 1.7.7. The notch views use sample notes, reminders, weather and device information; the clock and date may reflect when the snapshots were rendered. The settings image comes from the same demo mode. Each image is at least 1366 × 768 pixels. Review the images against the final Store build before uploading.

- `holm-today.png` — Today view
- `holm-notes.png` — notes
- `holm-reminders.png` — reminders
- `holm-calculator.png` — calculator
- `holm-settings.png` — settings

- holm-beam-choose.png — choose a recipient
- holm-beam-receive.png — accept or decline an incoming file
- holm-beam-sending.png — transfer progress
- holm-music.png — music playback
